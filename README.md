## Core Patterns

- **Letter Of Response Reviewer**: Letter of Response Standard: acknowledge reviewer feedback, cite concrete diff changes, and present benchmark data for disagreements.
- **Practical Application**: High-stakes PR comment threads and controversial code review discussions.
- **Verification Gate**: Enforces clean syntax, zero filler, and deterministic causality.
